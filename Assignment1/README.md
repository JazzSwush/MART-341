# Keyboard Website
## This website will guide you to making your own kayboard or finding one.
This is a guide to help you choose the right keyboard for you. There will be information on the layout of your keyboard, cases you can choose, switches to look at, and keycaps to consider. All this information is for your to know what you want in your keyboard. It is a simple website to help viewers learn more about keyboards and know what to look for when building their keyboard. Or a place for information on finding a keyboard. There is not a whole lot of information, but just enough to get started and inspired. I changed things up when I first started drafting this website. I initially had all the information on the home page, but decided to break it up into different pages so it is not too overwhelming when you first boot up the website. I kept my design simple and added as much pictures necessary for people to start visualizing what keyboard they want. I learned many things to building this website like added classes to highlight certain words, or even working in CSS. I have only worked with HTML and JavaScript and not much CSS. It helps with the visuals and a great learning process for design. One thing I could improve on in this website is my design as a whole because I didn't add too much visual appeal since I kept it very simple. Overall, it was a great learning experience in my first steps in web design by adding code instead of just the design aspect.
